# Tindak lanjut audit antislop 001

Tanggal: 25 September 2026. Cakupan: dashboard `/dashboard` dan permintaan tambahan untuk menghapus alur cart/detail produk di storefront. Acuan awal: [audit-001](audit-001-2026-09-24.md). Pengujian browser dilakukan pada salinan data lokal yang terisolasi.

## Keputusan desain

Design Read: dashboard operasional konsinyasi bagi admin dan staf gerai, Bootstrap 5 dua panel, permukaan putih dan aksen gold dengan Poppins. Dial: **ENERGY 1 / RHYTHM 2 / MOTION 1**.

- Putih menjaga tabel dan formulir mudah dibaca; gold `#d4af37` menandai aksi utama dan seleksi tanpa dijadikan warna teks kecil pada latar putih.
- Sidebar 250 px dan menu geser ponsel mengikuti `DESIGN.md`; ringkasan, grafik, daftar, dan tabel memakai komposisi sesuai fungsi masing-masing.
- Poppins mengikuti pilihan pemilik proyek; ukuran input/tombol minimal 44 px menjaga keterbacaan dan target sentuh.
- Kartu hanya membingkai kelompok informasi; bayangan hanya pada modal, menu geser, dan pesan yang benar-benar melayang di atas halaman.
- Ikon dipakai untuk navigasi, pencarian, peringatan, dan aksi yang sesuai maknanya. Teks HelcoBali dipakai sebagai wordmark tanpa membuat logo/avatar baru.
- Gerak terbatas pada hover dan buka/tutup menu agar pergeseran panel mudah diikuti.

## Verifikasi interaktif

- Ringkasan awal: pesan belum ada data; grafik: pesan belum ada laporan; notifikasi tanpa data: pesan kosong dan Escape mengembalikan fokus.
- Gerai & produk: tambah masing-masing, lihat hasil; stok: tambah batch, detail, tutup tombol/Escape/klik di luar modal.
- Pengaturan: ubah stok minimum dan ambang kedaluwarsa; aksi Stok kritis membuka batch dengan kedua status; pencarian, filter gerai/produk/tanggal/status, serta Hapus filter mengubah tabel.
- Penjualan: catat terjual, rusak, retur, dan hitung fisik; rentang grafik berubah; rekonsiliasi: tandai tinjau lalu batalkan.
- Restok: ajukan, setujui, mulai produksi, kirim gagal saat stok kurang, buat batch produksi, tandai siap, kirim FEFO, staf mengonfirmasi terima; pengajuan kedua dapat ditolak.
- Refresh: catatan produksi dan stok tetap ada karena penyimpanan lokal sinkron pada aksi; toast bisa ditutup; wordmark menuju Ringkasan; tautan Kembali ke toko menuju `/`.
- Ponsel: menu dibuka lalu ditutup lewat Escape dan tombol; dialog tidak meluber pada lebar 320 px.
- Storefront: kartu Featured Roasts menuju `/explore`; URL lama `/cart` dan `/product/7` dialihkan ke `/explore`; ikon/badge keranjang dan notifikasi Added to Cart tidak lagi dirender.
- Chromium headless melaporkan **0 error console/page** pada alur di atas. `npm run lint`, `npm run build`, dan `node --test src/pages/dashboardModel.test.js` berhasil. Build hanya memberi peringatan ukuran bundle >500 kB, bukan kegagalan.

Data konsinyasi tetap lokal pada browser masing-masing perangkat; belum ada API konsinyasi pada backend proyek.
