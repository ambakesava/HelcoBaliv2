# Audit antislop 001: dashboard HelcoBali

Tanggal: 24 September 2026

Mode: AFTER

Cakupan: `/dashboard` di `frontend/src/pages/Dashboard.jsx` dan `Dashboard.css`, beserta gaya Bootstrap dan referensi merek yang digunakan proyek.

Audit ini menilai kode dashboard yang masih berupa perubahan lokal. Label **Data demo** di header dan footer sudah memberi konteks bahwa data bukan data operasional; temuan di bawah tidak menyamakan label tersebut dengan klaim bahwa transaksi tersimpan di server.

## Temuan bernomor

1. **HIGH | R-17 (Data & Numbers).** KPI stok, penjualan, tagihan, serta jumlah permintaan berasal dari `INITIAL_ROWS`, `INITIAL_REQUESTS`, dan `INITIAL_PRODUCTION`, bukan sumber data nyata; menurut R-17 angka statistik tanpa sumber nyata tetap tidak boleh ditampilkan, meskipun halaman diberi label Data demo. Bukti: [`Dashboard.jsx:7-66`](../frontend/src/pages/Dashboard.jsx#L7-L66), [`Dashboard.jsx:296-307`](../frontend/src/pages/Dashboard.jsx#L296-L307).

2. **HIGH | R-03 (Mobile Responsiveness).** Tombol `.btn-sm`, input `.form-control-sm`, dan select `.form-select-sm` dipakai untuk aksi utama di ponsel tanpa tinggi sentuh minimum 44 px; aturan Bootstrap menghasilkan tinggi sekitar 31 px untuk kontrol kecil pada ukuran huruf bawaan. Bukti: [`Dashboard.jsx:251-257`](../frontend/src/pages/Dashboard.jsx#L251-L257), [`Dashboard.jsx:295`](../frontend/src/pages/Dashboard.jsx#L295), `frontend/node_modules/bootstrap/dist/css/bootstrap.css:2237-2241,2351-2357,3335-3340`; `Dashboard.css` tidak menaikkan ukuran kontrol pada breakpoint ponsel.

3. **HIGH | R-25 (Color Contrast).** Teks navigasi aktif berukuran 14 px memakai `#2470dc` di atas `#e9ecef`, dengan rasio terhitung **4,00:1**, di bawah WCAG AA 4,5:1 untuk teks normal. Bukti: [`Dashboard.css:9-10`](../frontend/src/pages/Dashboard.css#L9-L10), [`Dashboard.css:18-19`](../frontend/src/pages/Dashboard.css#L18-L19), variabel `--bs-secondary-bg` pada `frontend/node_modules/bootstrap/dist/css/bootstrap.css:89`.

4. **HIGH | R-32 (Keyboard Accessibility).** Saat modal atau sidebar ponsel dibuka, fokus tidak dipindahkan ke panel, tidak dibatasi di dalamnya, dan tidak dipulihkan saat tutup; tombol Escape hanya menutup modal, bukan sidebar ponsel. Pengguna keyboard dapat meneruskan Tab ke kontrol di belakang dialog. Bukti: [`Dashboard.jsx:192-195`](../frontend/src/pages/Dashboard.jsx#L192-L195), [`Dashboard.jsx:292-294`](../frontend/src/pages/Dashboard.jsx#L292-L294), [`Dashboard.jsx:311`](../frontend/src/pages/Dashboard.jsx#L311).

5. **HIGH | R-27 (UI States).** Tampilan stok mempunyai pesan kosong setelah filter, tetapi permintaan restok, produksi, riwayat laporan, dan rekonsiliasi hanya merender daftar/tabel; tidak ada representasi loading atau error untuk data yang ditampilkan. Bukti: [`Dashboard.jsx:261`](../frontend/src/pages/Dashboard.jsx#L261), [`Dashboard.jsx:266-275`](../frontend/src/pages/Dashboard.jsx#L266-L275), [`Dashboard.jsx:304-307`](../frontend/src/pages/Dashboard.jsx#L304-L307).

6. **HIGH | R-26 (Interactive Elements).** Aksi **Stok kritis** dapat menuju hasil kosong meskipun ringkasan menyatakan ada gerai kritis: jika batas kedaluwarsa diatur ke 30 hari, semua batch awal mendapat status *Segera kedaluwarsa* lebih dahulu sehingga filter *Stok kritis* tidak menemukan satu pun baris. Bukti: urutan kondisi [`Dashboard.jsx:79-85`](../frontend/src/pages/Dashboard.jsx#L79-L85), filter [`Dashboard.jsx:157-169`](../frontend/src/pages/Dashboard.jsx#L157-L169), aksi [`Dashboard.jsx:302`](../frontend/src/pages/Dashboard.jsx#L302), rentang pengaturan [`Dashboard.jsx:287`](../frontend/src/pages/Dashboard.jsx#L287).

7. **HIGH | R-02 (Copywriting).** Sel riwayat laporan memakai karakter em dash sebagai fallback nomor batch, padahal aturan melarang karakter tersebut pada teks UI. Bukti: fallback dengan karakter Unicode U+2014 pada [`Dashboard.jsx:306`](../frontend/src/pages/Dashboard.jsx#L306).

8. **HIGH | R-37 (Design Direction Required).** Tidak ditemukan `DESIGN.md` atau arahan visual khusus dashboard dalam proyek, sementara dashboard disajikan tanpa penanda *draft without direction* dan tanpa penetapan ENERGY/RHYTHM/MOTION; arahan desain yang ada di `desain-analisis.md` membahas aplikasi POS Laravel lain, bukan dashboard React ini. Bukti: [`Dashboard.jsx:290-301`](../frontend/src/pages/Dashboard.jsx#L290-L301), [`Dashboard.css:1-3`](../frontend/src/pages/Dashboard.css#L1-L3), [`desain-analisis.md:1-12`](../desain-analisis.md#L1-L12).

9. **MEDIUM | R-12 (Shadow).** `shadow-sm` dipakai berulang pada grafik, setiap kartu KPI, kartu permintaan, kartu tindakan, dan rekonsiliasi tanpa alasan elevasi yang tercatat; bayangan tidak membedakan prioritas informasi. Bukti: [`Dashboard.jsx:129`](../frontend/src/pages/Dashboard.jsx#L129), [`Dashboard.jsx:270`](../frontend/src/pages/Dashboard.jsx#L270), [`Dashboard.jsx:301-307`](../frontend/src/pages/Dashboard.jsx#L301-L307).

10. **LOW | R-20 dan R-31 (Visual Identity & Intentionality).** Shell mengikuti contoh dashboard Bootstrap dengan biru bawaan dan `system-ui`, berbeda dari bahasa merek storefront yang memakai hitam/amber serta Inter/Playfair; tidak ada alasan tertulis untuk perpindahan identitas tersebut. Bukti: [`Dashboard.jsx:291`](../frontend/src/pages/Dashboard.jsx#L291), [`Dashboard.css:3,10`](../frontend/src/pages/Dashboard.css#L3-L10), [`frontend/src/index.css:8-19`](../frontend/src/index.css#L8-L19).

## Verifikasi dan batas audit

- `npm run build` di `frontend/`: berhasil; Vite memperingatkan bundle JavaScript di atas 500 kB.
- `npx eslint src/pages/Dashboard.jsx`: berhasil.
- `npm run lint`: gagal pada lima error yang berada di `AddToCartModal.jsx`, `CartContext.jsx`, dan `Cart.jsx`, bukan pada dashboard.
- Kontras temuan 3 dihitung dari warna CSS aktual. Ukuran kontrol temuan 2 dihitung dari aturan Bootstrap bawaan, belum diukur lewat perangkat fisik.
- Click-through browser, konsol runtime, visual tiap breakpoint, dan fokus keyboard nyata **belum terverifikasi** karena browser/otomasi browser tidak tersedia di lingkungan audit; R-35 tidak dinyatakan lulus. Temuan yang memerlukan interaksi langsung perlu diuji kembali saat browser tersedia.
- Delivery Gate antislop untuk UI saat ini **FAIL** pada temuan yang tercantum; dokumen ini adalah audit kondisi saat ini, bukan penyerahan UI final.

Perbaikan hanya dilakukan untuk nomor temuan yang disetujui pemilik proyek, disertai laporan tindak lanjut setelahnya.
