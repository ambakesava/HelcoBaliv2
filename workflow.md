# Graphify System Rule

Before you generate code, modify architecture, or answer questions about how this project works, you MUST consult the local codebase map generated by Graphify.

## Core Instructions:

1. **Locate the Graph:** Always read the contents of the `graphify-out/` directory located in the root of this workspace before taking action.
2. **Trace Dependencies:** Use the structural data inside the map to understand how files, UI components, backend logic, and database schemas connect.
3. **Do Not Guess:** Never hallucinate file paths, imports, or method names. Rely strictly on the exact relationships defined in the graph.
4. **Vibecoding Alignment:** When making sweeping, multi-file architectural changes, ensure your proposed updates align seamlessly with the existing project structure mapped in `graphify-out/`.

## Auto-Update Requirement:

5. **Sync the Map:** Immediately after you write, modify, or delete any code in this project, you must automatically execute the `graphify .` command in the terminal to rebuild the knowledge graph.
6. **Fallback:** If you are in an environment where you cannot execute terminal commands directly, you must explicitly remind the user to run `graphify .` at the very end of your response.
